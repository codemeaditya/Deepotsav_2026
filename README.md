🪔 DEEPOTSAV – Celebrate the Festival of Lights

A Digital Celebration of India's Timeless Festival of Lights.

Deepotsav is an interactive web experience inspired by the beauty, traditions, and spirit of Diwali. It brings festive elements, music, camera interaction, and celebration together in one digital platform.

✨ Features

- 🪔 Beautiful Diwali-inspired interface
- 🎨 Premium festive design and animations
- 📸 Camera integration and photo capture
- 🪞 Photo preview and interaction
- 🎵 Traditional festive background music
- 🎉 Interactive celebration experience
- 📱 Responsive design for mobile and desktop

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Camera API

🚀 Getting Started

1. Clone this repository:

git clone YOUR_REPOSITORY_URL

2. Open the project folder.
3. Run "index.html" in your browser.
4. Allow camera permission when prompted.
